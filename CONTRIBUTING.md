# Contributing to FluxGrid

Thank you for contributing to FluxGrid.

This document defines the basic development workflow and engineering standards.

## Development Workflow

Before starting work:

1. Pull the latest changes.
2. Create a dedicated branch.
3. Make focused changes.
4. Run tests.
5. Run type checking.
6. Run linting.
7. Format the code.
8. Open a pull request.

## Branch Naming

Use descriptive branch names.

Examples:

```text
feature/job-management
feature/authentication
feature/worker-processing
fix/job-retry
fix/auth-token
refactor/queue-service
docs/api-documentation
test/job-service
