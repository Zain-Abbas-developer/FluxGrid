# FluxGrid AI Context

This directory contains project-specific instructions and context for AI-assisted development.

## Purpose

The `.ai` directory helps AI coding assistants understand:

- Project architecture
- Backend conventions
- Database conventions
- Security requirements
- Testing requirements
- Coding standards
- Deployment architecture
- Product requirements
